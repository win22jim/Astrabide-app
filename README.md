# Astrabide

A hardcore sci-fi tower defense game for iPhone and iPad. A self-replicating alien swarm is pouring out of a rift in space, and humanity's frontier is a line of automated gun emplacements. Build and upgrade towers beside the swarm's route, counter every enemy type, survive five bosses across fifty waves on each map — then keep going in Endless. Or draw your own maps in the Map Creator.

Free, with no ads and no in-app purchases. Plays fully offline.
